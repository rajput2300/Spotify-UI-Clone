# Spotify Clone (UI Only) 🎧

A static Spotify homepage clone built using pure HTML and CSS.

## Features
- Spotify-like dark UI
- Trending songs section
- Popular artists layout
- Sidebar navigation
- hover effect

## Tech Stack
- HTML5
- CSS3

## Notes
- This is a **UI-only project**
- No JavaScript functionality yet
- Not fully responsive (desktop-first design)

## Purpose
This project was built to practice:
- CSS layouts
- Flexbox / Grid
- Real-world UI cloning
